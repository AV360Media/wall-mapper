Cloud sync setup

One-time setup, about five minutes. Create a free project at supabase.com, then:
  1. Open SQL Editor, paste the block below, and run it.
  2. Open Project Settings → API Keys and copy the Project URL and the publishable key (sb_publishable_…). On older projects this is the anon public key instead — either works.
  3. Paste both here. The publishable key is meant to live in client code; the row-level security policy above is what protects your data. Never paste a secret key — it bypasses that policy.
